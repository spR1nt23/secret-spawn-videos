# secret-spawn-videos

Daily Roblox news videos for the **Secret Spawn** YouTube channel: 3 Shorts + 1 long video per day.

- **WORKFLOW.md**: the complete production method in Turkish: setup, research, script, voice, render, QA, metadata, schedule, upload.
- **TOPICS_HISTORY.md**: topics and codes already covered. Read it before picking new ones.
- **tools/**: the pipeline. Start with `bash tools/setup.sh`, then run `bash tools/make_day.sh content/YYYY-MM-DD.py`.
- **content/**: one script per day, plus `TEMPLATE.py`.
- **videos/YYYY-MM-DD/**: finished mp4s ready for upload.
